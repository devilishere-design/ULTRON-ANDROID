# ULTRON Android

A personal Android voice assistant with Hindi voice commands.

## Planned features
- Voice listening ON/OFF
- Hindi and English commands
- Open installed apps
- Torch and volume controls
- Call contacts with confirmation
- WhatsApp message drafts
- Online and offline basic commands

## Security
ULTRON will use Android permissions and supported APIs. It will not bypass device security or control another person's phone without permission.
